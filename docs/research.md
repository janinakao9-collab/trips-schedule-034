# 研究操作與規則對照

尚未執行真實使用者研究。功能測試不代表核心產品假設已成立。

## 三類腳本

1. 景點休館：使用主動回報，讀取今日公告與固定時間差異，選擇咖啡店方案，說明營業資訊是否已確認。
2. 交通延誤：從既有行程點需要調整，比較公車與等候；說明公車狀態和目的地開放衝突。其他推薦分類無候選。
3. 餐廳無法前往：比較附近食堂與市場，選擇下一步並說明非官方資訊的限制。

每個腳本可從任一入口啟動。研究者記錄是否形成可執行決策、理解可信度、錯誤採信、額外查證與卡點。來源點擊只能代表開啟來源，不代表理解；外部工具查證需補記，無記錄是未評估。

## 指標（每個工作階段）

- 決策完成率（暫定）：完成可執行決策任務數／全部啟動任務數。
- 錯誤採信率：將不確定資訊誤認已確認的任務數／呈現仍需確認或無法確認的任務數。
- 每個任務只計一次，未評估時標示資料不完整；零分母為不適用。沒有數據基線或量化達標門檻。
- 範例：兩個任務都呈現未知資訊，一個完成、一個未完成，且兩者皆評估無誤採信，則完成率 1/2、錯誤採信率 0/2；任一相關評估缺漏便不輸出確定率。

GO：大致能完成應變、理解可信度且無明顯錯誤採信。REVISE：反覆卡在資訊理解、比較或操作。STOP / REFRAME：流程可理解但無法降低決策負擔、仍完全返回原工具。由研究者判讀，不自動給結論。

## 可信度驗收對照

- Missing source timestamp／No usable evidence：咖啡店時間不明、原餐廳無來源。
- Inspect recommendation evidence：推薦卡與摘要可展開來源，更新與取得時間分開，無連結明示。
- Official static hours／Non-official information：公園固定開放、食堂旅客分享皆仍需確認。
- Current transport disruption／Today-specific closure：電車目前延誤、美術館今日公告。
- Scheduled event outside current interval：domain 測試有效區間終點與過期公告回退。
- Event notice overrides regular hours：美術館今日休館優先於固定開放。
- Conflicting current announcements：目的地同時段開放與休館衝突。
- Mixed evidence：替代公車已確認、目的地無法確認仍可選擇，沒有整段行程已確認保證。

情境內「已確認」只表示符合模擬證據規則，不表示真實世界今日狀態。區間包含起點、不含終點，以目的地時區判定。
