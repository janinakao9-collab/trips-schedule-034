## 重現步驟

1. 執行 `pnpm test`、`pnpm typecheck`、`pnpm build`，確認成功。
2. 執行 `pnpm dev`，開啟終端機顯示的本機網址。
3. 選擇休館、交通、餐廳情境，各從主動回報與既有行程「需要調整」進入結果，選擇方案、返回比較、修改脈絡。
4. 將視窗設為 390px 寬，以 Tab 移動、Enter 啟動按鈕與來源明細，Space 切換核取方塊；選未知方案後確認摘要仍保留未知資訊。
5. 在研究記錄補記評估後匯出 JSON，確認任務與評估；返回旅程啟動新任務，再點品牌重設，確認新任務標為放棄、前筆記錄保留。

這是功能驗收，不是使用者研究成果；尚未證明決策負擔改善或錯誤採信下降。
