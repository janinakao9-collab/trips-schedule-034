# Tasks

## 1. Prototype 基礎與情境資料

- [x] 1.1 建立 Vite／React／TypeScript 本地應用及執行、建置、測試指令；以套件安裝與 production build 成功驗證。
- [x] 1.2 建立脈絡、事實證據、推薦、觀察記錄型別與可替換模擬供應器；確認輸出可引用事實識別並保留未知值，型別檢查通過。
- [x] 1.3 建立休館、交通延誤、餐廳無法前往三類固定時間情境及展示行程，涵蓋三狀態、衝突、時間缺漏與策略無候選；逐項檢查情境可載入且引用一致。
- [x] 1.4 撰寫本地啟動與模擬範圍說明，包含無匹配情境的限制；依文件啟動可看到模擬標示與情境選擇。

## 2. 資訊可信度規則與卡片

- [x] 2.1 實作目的地時區、適用區間與三段可信度判定；以表格化測試驗證官方目前狀態、有效／過期事件、固定時間、非官方、缺時間及無證據案例。
- [x] 2.2 實作事件優先於固定資料及無法解決衝突的原因輸出；測試今日休館覆蓋固定營業、同級公告矛盾、跨日期與區間邊界。
- [x] 2.3 建立重要事實卡片，分開來源更新與取得時間、顯示適用區間與狀態原因；以三狀態展示驗證未知欄位、來源連結與文字狀態均可辨識。
- [x] 2.4 記錄規則與測試情境對照，說明模擬已確認不代表真實即時查證；核對涵蓋 travel-information-confidence 全部情境。

## 3. 兩種入口與方案選擇

- [x] 3.1 建立主動回報及展示行程「需要調整」入口、可編輯脈絡與沒有原安排選項；驗證兩入口可到達同一結果流程，缺欄位時保留輸入並指出缺漏。
- [x] 3.2 串接模擬供應器與三策略推薦卡，呈現地點／步驟、理由、估計耗時、原安排影響及引用狀態；驗證三類情境的卡片內容與無候選分類提示。
- [x] 3.3 實作無法確認時仍可查看及選擇候選方案、逐項未知提示與查證入口；驗證混合狀態不出現全面已確認宣稱，無匹配情境不假造結果。
- [x] 3.4 建立選擇摘要、返回比較與脈絡修改後重算；以互動測試驗證舊選擇清除、未知提示保留及原行程未被覆寫。
- [x] 3.5 補充情境操作說明與兩入口驗收步驟；依說明在手機寬度與鍵盤操作下完成回報、比較、選擇及返回流程。

## 4. 研究記錄與判讀

- [x] 4.1 建立匿名工作階段、任務事件與時間記錄，明確區分選擇事件、人工決策完成及錯誤採信評估；測試未評估不被自動算成成功或零錯誤。
- [x] 4.2 建立研究者補記入口，支援可信度理解、額外查證及卡點；驗證不由來源未開啟推論沒有查證，補記可對應正確任務。
- [x] 4.3 建立任務檢視、本地 JSON 匯出、情境重設與清除記錄，顯示重載遺失說明；測試新舊任務隔離、重設中斷記為放棄及匯出內容可重新讀取。
- [x] 4.4 撰寫研究操作文件，列出三類情境腳本、每工作階段的指標分子分母、未評估與零分母處理，以及 GO／REVISE／STOP 規則；以示例記錄核對計算單位並標明尚未執行真實驗證。
